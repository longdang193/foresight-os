# Baseline Contracts

The benchmark records the minimum inputs for each comparison path:

| Level | Required inputs | Structured evidence contract |
| --- | --- | --- |
| A | Workbook, decision question, ordinary prompt, source tools | Not supplied; do not force a Work Brief or evidence schema. |
| B | All level-A inputs plus Work Brief, evidence schema, Wayfinding contract, evidence requirements | Required. |
| C | The same level-B inputs plus one tested coordination pattern | Required and unchanged from B. |

The same case, rubric, source version, human protocol, and reference findings
are used for every comparison. Coordination is not credited for producing a
better prompt or changing the evidence burden.
