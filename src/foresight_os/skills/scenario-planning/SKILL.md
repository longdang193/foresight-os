# Scenario Planning

## Inputs
- A target decision, material assumptions, uncertainties, and signposts.

## Use when
- Multiple plausible futures materially change the recommended action.

## Steps
1. Select a small set of decision-relevant uncertainties.
2. Describe distinct, internally coherent scenarios.
3. Map implications, no-regret actions, and signposts.
4. Keep scenarios conditional and avoid presenting them as forecasts.

## Output
- Scenario set, assumptions, implications, actions, and monitoring signposts.

## Abstention
- Abstain when the decision or uncertainty boundary is not specific enough to compare.
